# GR1D-TD Simple Startup Guide
# 1. Go to the .jar file in location ((your file directory to project)...\GR1D-TD\lwjgl3\build\libs) and start the program
# 2. If that does not work, launch the program from Netbeans
# 3. Select a tower (Either Minigun or Sniper) from the shop on the right side of the screen
# 4. Place the tower by clicking any of the green outlined squares with a black center
# 5. Save up money for more towers to increase your defenses 
# 6. Click on an already placed tower and then click the Delete button that pops up to delete a tower for 50% of the cost
# 7. To pause the game by clicking the pause button in the shop
# 8. To resume the game, click the resume (play) button that was in the same spot as the pause button
# 9. Continue playing by placing towers and try to survive as long as possible. Watch as the difficulty increases as you play
# 10. When satisfied with play time, continue to step 10 to see some of the final features of the game
# 11. To test the health feature, restart the game (exit and re-launch), but do not purchase any towers, and let the health decrease to zero
