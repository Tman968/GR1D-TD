# GR1D-TD Simple Startup Guide
# 1. Go to the .jar file in location (add location) and start the program
# 2. If that does not work, launch the program from Netbeans
# 3. Select a tower (Either Minigun or Sniper) from the shop on the right side of the screen
# 4. Place the tower by clicking any of the green outlined squares with a black center
# 5. Save up money for more towers to increase your defenses
# 6. To pause the game by clicking the pause button in the shop
# 7. To resume the game, click the resume (play) button that was in the same spot as the pause button
# 8. Continue playing by placing towers and try to survive as long as possible. Watch as the difficulty increases as you play
# 9. When satisfied with play time, continue to step 10 to see some of the final features of the game
# 10. To test the health feature, restart the game (exit and re-launch), but do not purchase any towers, and let the health decrease to zero
